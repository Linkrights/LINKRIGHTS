# 이미지 넣는 곳

여기에 사진 파일을 넣으면 사이트에서 사용할 수 있습니다.

## 넣는 방법

1. 사진 파일을 이 폴더에 넣습니다. (파일 이름은 영어 소문자 + 하이픈, 예: `mentoring-2026.jpg`)
2. `content/programs.json` 을 열고 해당 항목의 `"image"` 값에 파일 이름만 적습니다.

   "image": "mentoring-2026.jpg"

3. 사진이 없으면 `"image": ""` 로 두세요. 색 배경이 자동으로 들어갑니다.

## 사진 가이드

- 가로가 긴 사진(3:2 정도)이 가장 잘 보입니다.
- 한 장에 500KB 이하를 권장합니다. (크면 휴대폰에서 느려집니다)
- 청소년의 적극적이고 주체적인 모습(활동·발표·배움)을 담아주세요.
- 얼굴이 나오는 사진은 반드시 본인과 보호자의 동의를 받은 뒤 사용하세요.
