# 이야기 나누기(커뮤니티) 여는 방법

사이트에 **구글 계정으로 들어와 글을 쓰고 댓글을 다는 공간**입니다. 승인 절차는 없습니다.
지금은 꺼져 있고, 아래 두 가지를 넣으면 열립니다. **모두 무료 범위 안에서 돌아갑니다.**

- 저장소: 관리자 페이지와 같은 Neon Postgres (`DATABASE_URL` — 이미 연결되어 있습니다)
- 로그인: 구글 OAuth (무료)

---

## 1. 구글 로그인 만들기 (10분)

1. <https://console.cloud.google.com/> 접속 → 구글 계정으로 로그인
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 `LINKRIGHTS` → 만들기
3. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면**
   - User Type: **외부(External)** → 만들기
   - 앱 이름 `LINKRIGHTS`, 사용자 지원 이메일·개발자 연락처: 팀 이메일
   - 범위(Scopes)는 **아무것도 추가하지 마세요.** (우리는 `openid` 하나만 씁니다)
   - 저장 후 **게시(Publish app)** 를 눌러 테스트 모드를 벗어나세요.
     (테스트 모드에서는 따로 등록한 사람만 로그인할 수 있습니다)
4. 왼쪽 메뉴 **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 유형: **웹 애플리케이션**
   - **승인된 리디렉션 URI** 에 아래 두 줄을 추가:
     - `https://linkrights.org/api/community/callback`
     - `https://www.linkrights.org/api/community/callback`
   - 만들기 → **클라이언트 ID** 와 **클라이언트 보안 비밀** 을 복사해 둡니다.

## 2. Vercel 환경변수 세 개 넣기

Vercel → LINKRIGHTS → Settings → Environment Variables

| 이름 | 값 | 모양 |
| --- | --- | --- |
| `GOOGLE_CLIENT_ID` | 1단계에서 복사한 **클라이언트 ID** | `123456789012-abc...xyz.apps.googleusercontent.com` |
| `GOOGLE_CLIENT_SECRET` | 1단계에서 복사한 **클라이언트 보안 비밀** | `GOCSPX-...` |
| `COMMUNITY_SECRET` | 아무도 모르는 긴 글자 (32자 이상 아무렇게나) | `k3n8x...` (직접 지어내면 됩니다) |

> ⚠️ **가장 흔한 실수**: `GOOGLE_CLIENT_ID` 에 프로젝트 이름이나 앱 이름(`linkrights` 같은)을 넣는 것입니다.
> 클라이언트 ID는 반드시 **`.apps.googleusercontent.com` 으로 끝나는 긴 글자**입니다.
> **사용자 인증 정보(Credentials)** 화면의 *OAuth 2.0 클라이언트 ID* 목록에서 이름을 눌러야 나옵니다.
> (OAuth 동의 화면에 적은 앱 이름과는 다른 값입니다)
> 잘못된 값을 넣으면 커뮤니티는 열리지 않고 `/admin` → **이야기 나누기** 탭에 무엇이 잘못됐는지 나옵니다.

`COMMUNITY_SECRET` 은 로그인 쪽지 서명과 계정 번호 변환에 씁니다.
**이 값을 바꾸면 기존 이용자가 모두 새 사람으로 보이니, 한 번 정하면 바꾸지 마세요.**

## 3. 다시 배포

Deployments → 맨 위 → **Redeploy**
`/ko/community` 에 들어가 **“구글 계정으로 시작하기”** 가 보이면 끝입니다. 표는 자동으로 만들어집니다.

---

## 무엇을 저장하나요

| 저장하는 것 | 저장하지 않는 것 |
| --- | --- |
| 구글 계정 번호를 **되돌릴 수 없게 바꾼 값** | 이름, 이메일, 프로필 사진 |
| 사이트가 지어 준 **별명** (이용자가 바꿀 수 있음) | 구글 계정 번호 원본 |
| 글·댓글의 내용과 시각 | 나이, 학교, 지역 |
| 신고를 눌렀다는 기록 | 접속 기록(IP) — 횟수 제한에만 쓰고 저장하지 않음 |

구글에는 `openid` 범위만 요청하므로, 이메일 주소는 받아오지도 않습니다.

## 운영팀이 할 일

관리자 페이지(`/admin`)에 **“이야기 나누기”** 탭이 있습니다.

- 신고가 많은 글·댓글이 맨 위에 옵니다.
- **숨기기**: 사이트에서 보이지 않게 합니다. (되돌릴 수 있습니다)
- **지우기**: 완전히 지웁니다. (되돌릴 수 없습니다)
- **글쓴이 차단**: 그 사람이 더 이상 글·댓글을 쓸 수 없게 합니다. 읽기는 됩니다.

신고가 **3번** 쌓이면 글이 자동으로 숨겨집니다. 운영팀이 확인하고 되살리거나 지우면 됩니다.

## 규칙과 안전

- 글 쓰는 칸 위에 이용 규칙이 항상 보입니다. (욕설·차별·개인정보·광고 금지, 만 14세 미만은 보호자와 함께)
- 글을 올리기 전에 전화번호·등록번호처럼 보이는 글자가 있으면 먼저 알려 주고, 한 번에 지울 수 있습니다.
- 한 사람이 5분에 5번까지만 올릴 수 있습니다.
- 커뮤니티 화면은 검색 결과에 나오지 않습니다. (robots.txt + noindex)

## 무료 범위

- Neon 무료: 저장공간 0.5GB — 글 수십만 개를 담을 수 있습니다.
- 구글 OAuth: 무료, 사용량 제한 없음.
- Vercel 무료: 커뮤니티 화면은 매번 새로 그리므로(force-dynamic) 함수 호출을 씁니다. 하루 수천 명까지는 무료 범위입니다.

## 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| **“The OAuth client was not found” (401)** | `GOOGLE_CLIENT_ID` 가 `.apps.googleusercontent.com` 으로 끝나는지. 프로젝트 이름을 넣으면 이 오류가 납니다 |
| **“redirect_uri_mismatch”** | Google Cloud Console 의 승인된 리디렉션 URI 가 `https://linkrights.org/api/community/callback` 과 **글자 하나까지** 같은지 |
| “준비 중이에요” 만 보임 | 환경변수 세 개가 모두 있는지, 다시 배포했는지. `/admin` → 이야기 나누기 탭에 이유가 나옵니다 |
| 구글 로그인 후 `login=failed` | 리디렉션 URI 가 정확히 같은지(`https://`, 끝의 `/` 없음) |
| “이 앱은 확인되지 않았습니다” 경고 | OAuth 동의 화면에서 **게시(Publish)** 를 눌렀는지 |
| 로그인은 되는데 글이 안 써짐 | `DATABASE_URL` 이 있는지, Vercel 로그에서 `[community]` 줄 확인 |
