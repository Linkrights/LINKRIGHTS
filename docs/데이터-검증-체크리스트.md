## 3. 긴급 안내 확인 (`content/emergency.json`)

- ☐ 긴급 연락처 목록이 적절한가 (112, 119, 1366, 117, 1388, 1577-1366)
- ☐ 안내 문구가 청소년이 읽기에 부담스럽지 않은가
- ☐ 4개 언어 문구가 모두 자연스러운가 (가능하면 원어민 검토)
- ☐ 감지 키워드에 **불필요하게 자주 걸리는 단어**가 없는가
  (예: "폭력"이 들어간 일반 질문에도 긴급 카드가 뜨는지 실제로 테스트)

## 4. 기능 테스트 (휴대폰으로 직접 해보기)

- ☐ 홈에서 질문을 입력하고 답변이 나오는가
- ☐ 답변에 나오는 **전화번호를 눌렀을 때 전화 앱이 열리는가**
- ☐ 답변에 등록되지 않은 기관이나 번호가 섞여 있지 않은가
- ☐ 등록된 자료와 무관한 질문(예: "내일 날씨 알려줘")에 **모른다고 답하는가**
- ☐ "누가 저를 때렸어요" 라고 입력했을 때 **긴급 카드가 먼저 나오는가**
- ☐ 언어를 English / 中文 / Tiếng Việt 로 바꿨을 때 메뉴가 바뀌는가
- ☐ 번역이 없는 글에서 "아직 번역되지 않았습니다" 안내가 나오는가
- ☐ 모든 분야 카드를 눌렀을 때 목록이 정상적으로 열리는가
- ☐ 키보드 Tab 키만으로 메뉴 → 본문 → 링크 순서로 이동되는가
- ☐ 개인정보 처리방침 페이지가 열리는가

## 5. 보안·운영 확인

- ☐ 브라우저에서 `Ctrl+U`(소스 보기) 후 `sk-` 를 검색했을 때 **아무것도 나오지 않는가**
- ☐ GitHub 저장소에 `.env.local` 파일이 올라가 있지 않은가
- ☐ OpenAI **Hard limit(하드 리밋)** 을 설정했는가
- ☐ OpenAI **Soft limit(알림)** 이메일 수신 주소를 확인했는가
- ☐ `content/site.json` 의 문의 이메일이 실제로 확인 가능한 주소인가
- ☐ `NEXT_PUBLIC_SITE_URL` 이 실제 사이트 주소로 설정되어 있는가
- ☐ GitHub·Vercel·OpenAI 계정 소유자와 인수인계 방법을 정해두었는가
