# 관리자 페이지 설정 안내

이용자가 사이트에서 보낸 **질문 · 참여 문의 · 정보 수정 제보**를 운영팀이 한곳에서 읽고 답할 수 있는 화면입니다.
주소는 `https://linkrights.org/admin` 이고, 아래 두 가지를 등록해야 열립니다.

설정하기 전까지 사이트는 예전과 똑같이 동작합니다. (글 보내는 칸 대신 문의 메일 주소가 보입니다)

---

## 1. 데이터베이스 연결하기 (한 번만)

1. Vercel 대시보드 → LINKRIGHTS 프로젝트 → **Storage** 탭
2. **Marketplace Database Providers** 에서 **Neon** 을 고르고 **Create**
   - 지역은 서울(icn1) 또는 가까운 곳, 요금제는 **Free** 로 충분합니다.
3. 만들어진 데이터베이스를 LINKRIGHTS 프로젝트에 **Connect** 합니다.
   - 연결하면 `DATABASE_URL` 환경변수가 프로젝트에 자동으로 들어갑니다.
   - 표(테이블)는 사이트가 처음 글을 받을 때 알아서 만듭니다. SQL 을 직접 실행할 필요가 없습니다.

> Vercel 이 직접 운영하던 Postgres 는 2025년에 없어졌고, 지금은 마켓플레이스의 Neon 을 씁니다.

## 2. 관리자 비밀번호 정하기

1. Vercel 대시보드 → LINKRIGHTS 프로젝트 → **Settings** → **Environment Variables**
2. 이름 `ADMIN_PASSWORD`, 값은 **8자 이상**으로 팀이 정한 비밀번호
3. 적용 범위는 **Production** (원하면 Preview 도 함께)

- 비밀번호는 코드 어디에도 들어 있지 않습니다. 여기에서만 바꿉니다.
- 비밀번호를 바꾸면 로그인해 둔 사람은 모두 다시 로그인해야 합니다.
- 팀원끼리 한 개를 같이 씁니다. 사람마다 계정을 만들려면 따로 이야기해 주세요.

## 3. 다시 배포하기

환경변수를 넣은 뒤 **Deployments → 맨 위 배포 → Redeploy** 를 누릅니다.
다시 배포해야 사이트 화면에 글 보내는 칸이 나타납니다.

---

## 쓰는 방법

1. `https://linkrights.org/admin` 에 들어가 비밀번호를 넣습니다. (12시간 동안 로그인 유지)
2. 위쪽 단추로 묶음을 고릅니다.
   - **질문** — 질문 게시판으로 온 질문
   - **참여 문의** — 멘티 · 대학생 멘토 · 학교/기관
   - **정보 수정 제보** — 전화번호·링크가 바뀌었다는 제보
   - **도움이 됐나요** — 날짜·언어·분야별 도움됨/아쉬움 횟수
3. 글마다 할 수 있는 일
   - **답변 저장** — 답을 적고 저장합니다. (상태가 "답변함"으로 바뀝니다)
   - **게시판에 올리기** — 질문에만 있습니다. 누르면 5분 안에 질문 게시판에 보입니다.
   - **숨김 / 스팸** — 게시판에서 감춥니다.
   - **지우기** — 되돌릴 수 없습니다. 이용자가 삭제를 요청했을 때 씁니다.

### 답할 때 지켜야 할 것

- 게시판에 올릴 때는 **이름·연락처·학교 이름처럼 개인을 알아볼 수 있는 내용을 지우고** 올립니다.
- 답변에는 **등록된 권리정보와 기관**만 근거로 씁니다. 없는 기관·전화번호·주소를 지어내지 않습니다.
- 답장 받을 곳(연락처)은 답장에만 씁니다. 다른 곳에 옮겨 적지 않습니다.
- 만 14세 미만으로 보이는 글에 연락처가 적혀 있으면, 보호자·선생님과 함께 연락하도록 안내합니다.

## 저장되는 것

| 표 | 무엇이 들어가나 |
| --- | --- |
| `lr_submissions` | 보낸 내용, 제목, 화면 언어, 보낸 날짜, (적었을 때만) 답장 받을 곳, 상태, 답변 |
| `lr_helpful` | 날짜·종류·언어·분야·근거·도움됨 여부별 **횟수 숫자만** |

- AI 질문과 답변 내용은 예전과 같이 **저장하지 않습니다.**
- 접속한 인터넷 주소(IP)는 같은 사람이 너무 많이 보내는 것을 막는 데에만 잠깐 쓰고 저장하지 않습니다.
- 권리정보·기관 데이터는 그대로 `content/*.json` 에서만 옵니다. 데이터베이스와 상관없습니다.

이 내용은 개인정보 처리방침(사이트 하단 링크)에도 같은 말로 적혀 있습니다. 저장하는 항목을 바꾸면 방침도 함께 고쳐야 합니다.

## 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| `/admin` 에 "아직 준비가 끝나지 않았습니다" | `DATABASE_URL` 과 `ADMIN_PASSWORD` 가 들어갔는지, 다시 배포했는지 |
| 비밀번호가 맞지 않는다고 나옴 | 환경변수 값 앞뒤에 빈칸이 들어갔는지 확인 |
| 사이트에 글 보내는 칸이 안 보임 | 환경변수를 넣은 뒤 **Redeploy** 를 했는지 |
| 보내기를 눌렀는데 "보내지 못했어요" | Vercel → Logs 에서 `[submit]` 으로 시작하는 줄을 확인 |
| 글이 게시판에 안 보임 | 관리자에서 **게시판에 올리기**를 눌렀는지, 누른 뒤 5분이 지났는지 |
